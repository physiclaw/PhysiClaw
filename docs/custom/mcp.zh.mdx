PhysiClaw 通过 MCP 把底层硬件封装成 `peek`、`tap`、`swipe` 等工具，供你自己的智能体直接调用。

## 启动 MCP

```bash
physiclaw mcp
```

如果上次运行后硬件没有移动过，也可用 `physiclaw mcp -H` 热启动，复用已有校准数据并跳过校验。

## 连接 MCP

<Tabs>
<TabItem label="Claude Code">
```bash
claude mcp add --transport http physiclaw http://127.0.0.1:8048/mcp
```
</TabItem>
<TabItem label="Codex">
```bash
codex mcp add physiclaw --url http://127.0.0.1:8048/mcp
```
</TabItem>
<TabItem label="Gemini CLI">
```bash
gemini mcp add --transport http physiclaw http://127.0.0.1:8048/mcp
```
</TabItem>
<TabItem label="OpenClaw">
```bash
openclaw mcp add physiclaw --url http://127.0.0.1:8048/mcp --transport streamable-http
```
</TabItem>
<TabItem label="Hermes">
```bash
hermes mcp add physiclaw --url http://127.0.0.1:8048/mcp
```
</TabItem>
</Tabs>

## 使用

连接后，给你的智能体下达任务：

```text
帮我打开微信
```

:::note[注意 token 消耗]
每一步操作都会返回一张摄像头拍摄的屏幕图像，因此 token 消耗较高。任务步骤较多时，累计的图像和消息容易占满上下文窗口。
:::
