---
title: 记忆
description: PhysiClaw 如何在会话之间保持记忆。
---

智能体每次唤醒时，都会加载 `~/.physiclaw/memory/` 下的 Markdown 文件，读取之前保存的信息。

<FileTree>
- ~/.physiclaw/memory/
  - USER.md
  - memory.md
  - 2026-06-22.md
  - …
</FileTree>

| 文件 | 存放内容 | 维护者 |
| --- | --- | --- |
| `USER.md` | 你是谁、你的偏好、常用聊天软件 | 你 |
| `memory.md` | 你要求智能体记住的事项 | 智能体 |
| `YYYY-MM-DD.md` | 当天的活动日志，只追加不修改 | 智能体 |

## 示例

你可以创建 `USER.md`，记录自己的偏好和常用信息，这样每次开始会话时就不必重复说明。

```markdown
## 称呼
老张

## 聊天软件
微信（昵称：张三）

## 沟通
- 始终先回复消息，再执行操作
- 付款前先与我确认

## 常用信息
收货地址：北京市朝阳区 xx 路 xx 号

## 口味
不吃辣，咖啡要美式、不加糖
```

## 让它记住

记忆文件不需要手动修改。在对话中告诉 PhysiClaw 要记住的内容，它会自动写入 `memory.md`，之后每次会话都会记得。

:::tip[发信息]
记住我不吃香菜，点外卖时记得备注。
:::
