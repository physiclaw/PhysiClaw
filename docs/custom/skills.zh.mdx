---
title: 技能
description: PhysiClaw 如何学会某个 App 的操作流程。技能按文件夹存放，按需加载，保持提示词精简。
---

PhysiClaw 无需专门技能就能操作大多数 App。但智能体有时反复犯同一个错误，或多次尝试才能完成任务，浪费 token 和时间。这时可以创建技能，引导它高效完成特定任务。

## 创建技能

在 `~/.physiclaw/skills/` 下新建文件夹，用英文命名（例如京东购物技能命名为 `jd`），在其中创建 `SKILL.md`（全大写）文件。

<FileTree>
- ~/.physiclaw/skills/
  - jd/
    - SKILL.md
</FileTree>

### SKILL.md 示例

```markdown
---
name: jd
description: 在京东／七鲜购买生鲜蔬果、零食或日用品时使用。
---

# 京东购买生鲜

在京东七鲜购买生鲜商品。通过 MCP 工具查看屏幕，默认使用 `peek`，仅在必要时使用 `screenshot`。

## 流程

1. 打开「京东」，在首页进入「京东七鲜」。
2. 点击搜索框，输入商品名，进入商品页。
3. 点击「加入购物车」。如果弹出规格选择（重量、数量等），选定后点击「确定」。
   - **同一商品页不要重复点击「加入购物车」**，否则会重复添加。
4. 点击购物车图标，核对商品与数量，点击「去结算」。
5. 把商品、数量、价格、收货地址、运费、预计送达时间发送给用户，等待用户确认。
6. 用户确认后，点击「提交订单／立即支付」。

## 注意：截屏会触发分享弹窗

京东会检测 iOS 截屏并弹出「分享截屏」菜单。点击弹窗外变暗的区域即可关闭。
```

## 最佳实践

**description 决定技能是否触发。** description 始终在上下文中，技能正文只在触发后加载，因此 description 要写明使用场景和对应的 App，而不是泛泛描述功能。

**只写智能体还不知道或容易出错的内容。** 智能体已经能操作大多数 App，技能应补充它尚不了解的操作规则，或帮助它避免反复犯错。

**用明确的指令句，并说明原因。** 说明原因有助于智能体准确执行指令，也便于它处理类似情况。

**保持精简。** SKILL.md 越短，越省 token。

## 触发技能

给 PhysiClaw 发微信消息时，说明要用哪个 App，这样更容易触发对应技能。

:::tip[发信息]
帮我在京东买一瓶 400ml 鲜奶。
:::
