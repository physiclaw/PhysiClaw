一切就绪。

启动服务器：

```bash
physiclaw
```

启动后，浏览器会自动打开**硬件设置**页面。开启**自动模式**并点击**继续**，设置向导就会自动执行各步骤，只在需要你操作时暂停。

也可以跳过浏览器，直接在终端开启自动模式：

```bash
physiclaw auto
```

下次启动时，只要上次运行后设备没有移动过，就可以跳过设置和校验，直接开始：

```bash
physiclaw now
```

## 任务示例

确认 PhysiClaw 的手机已登录**微信**，计划使用的 App（美团、京东、淘宝等）也已登录，并设置好默认收货地址和支付方式。

用你自己的微信账号添加 PhysiClaw 的微信账号为好友，然后像平时聊天一样发消息，告诉它要做什么：

```text
帮我在美团上点一杯瑞幸美式。
明天天气怎么样？
明早 7 点把最新新闻发给我。
在京东七鲜买牛奶和鸡蛋。
帮我在 DeepSeek 上搜一下「xx 问题」。
```

:::tip[还没配置模型？]
使用智能体前，需要先配置大模型。尚未配置的话，请参阅[获取 API Key](/zh/set-up/provider/)。
:::
