PhysiClaw 用摄像头观察屏幕，用触控笔点击屏幕，为此需要建立两个映射：

一个是从**手机屏幕**到**摄像头画面**：屏幕上的按钮出现在摄像头画面的哪个位置。

另一个是从**手机屏幕**到**机械臂移动平面**：触控笔要移动多远才能点到这个按钮。

有了这两个映射，PhysiClaw 才能根据画面准确定位，让触控笔点中目标。

## 摄像头

校准前，在电脑上打开相机预览应用，调整手机位置和摄像头角度，确保：

- **屏幕尽量占满画面**
- **手机已放平**
- **屏幕在画面中不倾斜**

可查看摄像头画面的应用：

- **macOS**：Photo Booth
- **Windows**：相机
- **Linux**：Snapshot（或 Cheese）

:::caution[把手机垫平]
手机背面的摄像头凸起使手机无法平放。在手机下方垫一块裁成合适形状的薄卡纸或软垫，使屏幕保持水平、不晃动。
:::

## 设置

启动服务器：

<Tabs syncKey="os">
<TabItem label="macOS">

```bash
physiclaw
```

第一次读取摄像头时，macOS 会请求授权，点击**允许**。之后可在**系统设置 → 隐私与安全性 → 摄像头**中修改。

</TabItem>
<TabItem label="Windows">

```powershell
physiclaw
```

</TabItem>
<TabItem label="Linux">

当前用户需要加入 `video` 和 `dialout` 用户组，才能分别访问摄像头和串口。加入后，请**注销并重新登录**：

```bash
sudo usermod -aG dialout,video $USER
```

（Arch 系发行版的串口组是 `uucp`，不是 `dialout`。）

然后启动服务器：

```bash
physiclaw
```

</TabItem>
</Tabs>

服务器自动在浏览器中打开设置向导，逐步引导你完成校准。

### 自动模式

向导也可以自动运行。开启**自动模式**后，向导替你完成每个校准步骤。

如果已经校准过且没有移动硬件，可以开启自动模式。

## 首次运行

首次运行时，PhysiClaw 会在校准完成后花几分钟学习手机屏幕布局，确定聊天软件的输入框、发送按钮和屏幕键盘的位置。这一步全自动完成，无需操作。

确保**微信**已固定在底部栏（见[准备手机](/zh/set-up/prepare-the-phone/)），PhysiClaw 才能找到并打开它。学习完成后，即可向它分配任务。

:::tip[换了手机？]
运行 `physiclaw reset` 清除校准数据和已学习的屏幕布局，再重启 PhysiClaw，它会重新校准并学习新手机的界面。
:::
