---
title: 固件
description: 用一条命令给控制板烧录 FluidNC。
---

PhysiClaw 的硬件通过 [FluidNC](https://github.com/bdring/FluidNC) 固件与电脑通信。电脑发送 [G-code](https://en.wikipedia.org/wiki/G-code)（GRBL 协议）驱动电机、开关电磁铁，完成点击、滑动等手势。

## 准备工作

- [MKS DLC32 V2.1](https://github.com/makerbase-mks/mks-dlc32) 控制板。
- USB-B 转 USB-A 数据线。
- 12 V 2 A 电源。

## 烧录

用 USB 连接控制板，接通 12 V 电源，运行：

```bash
physiclaw flash
```

### 验证

确认两个电机和电磁铁已连接，然后运行：

```bash
physiclaw testdrive
```
