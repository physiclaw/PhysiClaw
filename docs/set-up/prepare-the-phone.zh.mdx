description: 在专用手机上做一次性 iOS 配置，让 PhysiClaw 能看见并操作它。两个快捷指令、辅助触控，以及专用锁屏密码。
---

给 PhysiClaw 准备一部**专用 iPhone**。不需要旗舰或最新机型，便宜的二手 iPhone 即可。

:::caution[PhysiClaw 将拥有这部 iPhone 的完全控制权限]
我们已尽力让智能体保护你的隐私、稳定运行、抵御攻击，但仍须做到以下几点：

- **退出 Apple ID**，避免智能体接触你的 iCloud 照片、通讯录和「查找」。
- **不要用这部手机的号码绑定重要账户**，否则控制了这部手机，就几乎等于能重置这些账户。
- **不要把任何账户的密码告诉智能体**。
- **只安装你打算让 PhysiClaw 使用的 App**。
- **不要安装敏感 App**：银行 App、支付或钱包 App、密码管理器。
- **如果确实需要支付**，开启**小额免密**，支付账户**只保留少量余额**，把损失控制在可承受范围内。
:::

## 设置微信

PhysiClaw 通过微信和你交流。

### 添加朋友

在这部手机上登录微信，和你自己的账号互加好友。PhysiClaw 通过这个聊天联系你，请将它置顶，使它始终位于聊天列表最上方。

### 把微信放到底部栏

把微信图标拖到底部栏，这样无论手机停在哪一屏，PhysiClaw 都能快速找到并打开它。

:::tip
微信是 PhysiClaw 联系你的唯一通道。图标和聊天的位置固定，它才能可靠地查看和回复消息。
:::

## 配置快捷指令

:::tip[连到同一个局域网]
把 iPhone 和运行 PhysiClaw 的电脑接入**同一个 WiFi**，快捷指令通过局域网和电脑通信。
:::

在电脑终端运行：

```bash
physiclaw test-assistive-touch
```

运行后会在终端显示主机名（hostname），并自动打开测试页面，用于验证截图上传和剪贴板功能。

### 上传截图

截取当前屏幕并直接上传到电脑，供智能体查看更清晰的画面。

<Steps>

1. 在**快捷指令** App 里，点击 **+** 新建。

2. 添加「**截屏**」。

3. 添加「**获取 URL 内容**」：
   - URL：`http://<hostname>.local:8049/api/bridge/screenshot`
   - **显示更多** → 方法 **POST**，请求体 **文件**，文件选择上一步「**截屏**」的输出

4. 重命名为 `PhysiClaw Upload Screenshot`。

</Steps>

### 拷贝到剪贴板

智能体把文字传到手机剪贴板再粘贴，比用触控笔逐键点击更快、更可靠。

<Steps>

1. 在**快捷指令** App 里，点击 **+** 新建。

2. 添加「**获取 URL 内容**」，URL 填 `http://<hostname>.local:8049/api/bridge/clipboard`，方法选 **GET**。

3. 添加「**拷贝到剪贴板**」，输入设为上一步的「**URL 内容**」。

4. 重命名为 `PhysiClaw Clipboard`。

</Steps>

## 开启辅助触控

辅助触控是 iOS 屏幕上的悬浮按钮「小白点」，机械臂单点即可截屏并上传，长按则将文字拷贝到剪贴板。

<Steps>

1. **设置 → 辅助功能 → 触控 → 辅助触控** → 打开。

2. 在**自定操作**里设置：
   - **单点** → **PhysiClaw Upload Screenshot**
   - **长按** → **PhysiClaw Clipboard**

</Steps>

### 验证设置

1. 单点辅助触控，确认电脑页面显示的是 iPhone 当前屏幕的截图。
2. 长按辅助触控，再在 iPhone 的「备忘录」中粘贴，确认文字与测试页面上的代码一致。

## 设置锁屏密码

PhysiClaw 能自行解锁手机，但只使用一个固定密码：`111111`。专用密码可避免你的常用密码经日志或配置文件泄露。把这部手机的锁屏密码设为 `111111`：

**设置 → 面容 ID 与密码 → 打开密码 → 输入 `111111`**

:::note[或者关闭自动锁定]
也可以关闭自动锁定（**设置 → 显示与亮度 → 自动锁定 → 永不**），让手机保持解锁。代价是屏幕常亮，老化更快。
:::

## 固定屏幕亮度

摄像头根据屏幕亮度调整曝光时间，自动亮度调节可能导致画面过曝或欠曝。关闭自动亮度调节，把亮度固定在 50% 或更高。

**设置 → 辅助功能 → 显示与文字大小 → 自动亮度调节 → 关闭**

## 允许从其他 App 粘贴

PhysiClaw 通过快捷指令把文字复制到剪贴板，粘贴到微信与你沟通，或粘贴到淘宝、京东搜索商品。
如果每次粘贴都弹窗要求确认，按如下设置免去提示：

**设置 →〔App 名称〕→ 从其他 App 粘贴 → 允许**
