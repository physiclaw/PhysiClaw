PhysiClaw 是能操作手机的智能体。它用摄像头观察屏幕，用触控笔点击，像人一样操作手机。

## PhysiClaw 能做什么？

目前的 AI 智能体主要面向技术工作，最擅长编程、文件处理等任务。但大多数人不写代码，许多日常事务都要通过手机处理，例如网购、点外卖、买火车票、医院挂号、叫车。这些任务与智能体擅长的领域几乎没有交集。

PhysiClaw 面向的正是这类日常任务。它不要求你掌握任何技术，也不依赖 App 开放接口，而是直接操作手机。凡是你能在手机上手动完成的事，PhysiClaw 都能替你完成。

## PhysiClaw 与 OpenClaw

| | PhysiClaw | OpenClaw |
|---|---|---|
| 擅长 | 日常事务 | 编程与技术工作 |
| 操作方式 | 物理操作手机 | 命令 / API / 浏览器自动化 |
| 硬件 | 专属硬件 + 手机 | 无 |
| 读写电脑文件 | 否 | 是 |
| 安全边界 | 不执行命令 | 拥有系统权限 |
| 被平台识别为自动化 | 物理操作难以识别 | 软件操作易被识别 |
| 微信聊天 | 直接和好友聊天 | 需逆向协议或第三方适配 |

**Python：** 3.12+
