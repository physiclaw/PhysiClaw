# Weather

Use the installed weather app or the app the user names. Confirm the city (the user's city if unspecified); select it from the city list or ask if unavailable. For a future day, open its forecast row. Report the exact displayed figures and relevant timing; scroll for details such as AQI, rain, or wind.
